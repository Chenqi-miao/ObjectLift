# MVP 验收清单

所有项目初始为待验证。替身测试不代表真实模型通过。

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| ENV-01 | GPU 环境 | 容器内 PyTorch CUDA 运算成功，记录版本和 GPU 架构 |
| GEN-01 | 官方单物体样例 | 真实 TripoSR 输出 GLB，可重新加载和旋转预览 |
| GEN-02 | 连续三次生成 | 无残留 worker，记录耗时、峰值与任务后显存 |
| IMG-01 | 上传 JPG/PNG | EXIF 方向正确；损坏文件提示；透明度保留 |
| DET-01 | 多物体检测 | 框对应归一化图片坐标，编号稳定，阈值可调 |
| CROP-01 | 边界裁剪 | 越界限制有效，无倒置或空框；可手动调整 |
| FG-01 | 前景 | 透明 PNG 有非透明像素；支持自行上传前景 |
| FLOW-01 | 状态更新 | 新图片、目标和前景变化后，下游结果失效 |
| FLOW-02 | 并发 | 全局同一时间一个生成任务，重复提交有提示 |
| ERR-01 | 失败重试 | 超时、OOM、空前景、进程异常可区分且可重试 |
| OUT-01 | 导出 | GLB 有有效网格，检查顶点颜色；PNG、JSON 可下载 |
| E2E-01 | 真实复杂图片 | 检测→选择→去背景→生成→预览→下载完成 |

## 每次真实测试记录

输入来源与许可、输入文件摘要、目标、裁剪参数、模型版本、依赖版本、
分阶段耗时、峰值显存、网格数量、颜色检查、主体可辨认程度、缺失与粘连、日志位置。

## 三分钟演示

1. 多目标图片检测并选择一个物体。
2. 调整裁剪，确认透明前景。
3. 提交生成并说明检测、去背景、重建的作用。
4. 旋转模型，说明背面与遮挡区域为推测。
5. 下载并重新打开 GLB。
6. 若使用历史生成结果，显式标注，不冒充现场结果。

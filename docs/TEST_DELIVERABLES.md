## 4. 模型质量与性能验收

计划100张图片、5段短视频，预先人工标注20条相关查询与5条无相关查询。Top-5命中率目标≥80%；视频结果须落入标注区间。抽样未覆盖的短事件应单列，不混入已支持场景后再隐藏失败。

已加载模型、1000检索单元时热查询P95目标≤3秒，至少20次查询。未缓存热查询和缓存查询分组；首次加载单列；注明服务端或浏览器端到端计时及分位数计算方法。

描述质量表记录正确内容、遗漏、错误对象/数量/动作、主观推断和标签问题。没有预先定义和实际执行的统计，不报告“理解准确率”。

## 2. 信息架构与布局

首页说明产品能力并提供工作台入口。工作台顶部搜索，左侧类型/标签/文件名筛选，中间素材网格，右侧预览详情；导入与处理操作收纳到对应区域，诊断信息分离展示。

【图 UI-02】四步操作插图可复用`report-assets/illustrated-user-flow-purple.png`，标明“操作示意”；最终汇报优先紫色版，绿色早期图不作为当前品牌示例。

【界面截图 UI-03】真实首页全景、工作台全景各一张，保留主要功能区域。标注1—4个重点即可，避免密集箭头遮挡界面。

## 3. 视觉规范

主色沿用首页紫色，背景采用浅紫/近白，文字使用深色；素材图片自身颜色保留。品牌图标沿用项目现有资产，不重新发明标志。精确色值、字号、圆角和间距应从当前样式提取，记录“当前值”与“建议值”，本稿不虚构已经统一的设计Token。

## 4. 核心交互说明

| 操作 | 设计要求 | 验证证据 |
| --- | --- | --- |
| 导入 | 逐文件结果，成功后可浏览，明确尚需建立索引 | 导入前后及异常截图 |
| 搜索 | 支持回车提交、结果数量调整、条件筛选 | 固定任务录屏 |
| 浏览与搜索切换 | 无查询可浏览；清除查询保留筛选 | 操作前后截图 |
| 选中素材 | 更新预览、信息、描述和下载入口 | 图片与视频详情对照 |
| 生成描述 | 明确手动触发，显示加载与生成阶段 | 等待/成功/失败状态 |
| 批量补齐 | 明确处理未完成/失败项并显示进度 | 批次范围与进度截图 |
| 视频定位 | 展示命中时间，跳转结果可核对 | 操作录屏与时间记录 |
| 回收站 | 明确可恢复及不释放空间 | 移除—恢复闭环 |

【界面截图 UI-06】图片详情与视频详情各一张，说明不同媒体的预览和信息差异。

【录屏 UI-07】60—90秒主流程演示，使用可公开样例，提前预热；预先生成的内容明确说明，不假装现场实时生成。

## 5. 状态设计与可用性

| 状态 | 用户需要知道什么 | 应有动作 |
| --- | --- | --- |
| 空库 | 尚未导入素材 | 导入入口 |
| 已入库未索引 | 可浏览但尚未进入语义检索 | 建立索引 |
| 模型处理中/繁忙 | 当前阶段、等待情况 | 避免重复触发，清楚的繁忙提示 |
| 无结果 | 当前查询或条件下无匹配结果 | 修改查询或筛选 |
| 失败 | 哪个文件、哪个阶段、什么原因 | 重试或更换输入 |
| AI生成完成 | 描述是模型输出，可对照画面核实 | 查看、按需重试 |
| 回收站 | 素材保留但不参与正常搜索 | 恢复 |

【界面截图 UI-08】状态拼图只使用真实截图；未实现的状态标“设计要求/待实现”，不能制作假截图证明功能存在。

【附件 UI-09】可用性任务表：参与者编号、任务、是否完成、耗时、误操作、原话反馈、问题级别、修复及复测。试用人数按实际填写，不编造访谈或满意度。

检查文字可读性、键盘基本操作、按钮状态、颜色之外的文字提示与窄屏堆叠。现有窄屏方式尚需设备实测，不能宣称已全面适配。

## 6. 交付验收与展示

所有关键操作均有明确入口与反馈；设计稿和实现状态对应；实际页面遵循紫色品牌；错误和等待状态有证据；视频定位与窄屏问题单独登记。

建议3页：信息架构与视觉规范；真实页面与操作演示；状态设计与试用问题。附件保留原始截图、概念图、规范板和反馈表。
